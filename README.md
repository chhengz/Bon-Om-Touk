# Bon Om Touk — The Cambodian Water Festival Web Application

An interactive, culturally rich web application celebrating Cambodia's Royal Water and Moon Festival (**Bon Om Touk** / ព្រះរាជពិធីបុណ្យអុំទូក).

## Highlights & Features

- **The Three Sacred Pillars (ពិធីទាំងបីនៃបុណ្យអុំទូក)**: Detailed cultural deep dives into the Dragon Boat Regattas (*Touk Ngor*), Illuminated Night Flotillas (*Loy Pratip*), and Full Moon Feast (*Sampeas Preah Khe & Auk Ambok*).
- **Interactive Tonle Sap Flow Reversal Simulator**: Visual basin telemetry demonstrating the unique hydrological reversal of the Tonle Sap river between the monsoon flood swell (up to 16,000 km²) and the November festival reversal.
- **Sacred Dragon Boat (Touk Ngor) Anatomy & Cadence Physics**: Interactive schematic with component hotspots and real-time velocity/sprint calculator based on rower count and stroke cadence, with Web Audio drum pulse playback.
- **Virtual Loy Pratip Floating Lantern Ceremony**: Interactive riverside experience where users select traditional lanterns (Lotus, Naga, Temple, Banana Leaf), write a personal blessing, and float it onto the river with community prayers.
- **Traditional Ambok Recipe & Legend**: Step-by-step culinary process and guest portion calculator for the sacred pounded young rice banquet, accompanied by the Jataka legend of the hare in the moon.
- **Angkorian Naval Roots**: 12th-century historical chronicles and bas-relief documentation from the Bayon temple galleries.
- **Phnom Penh Visitor Companion**: Prime vantage points along Sisowath Quay, official 3-day itinerary, street food guide, and festival etiquette.
- **Traditional Synthesized Soundscape**: Built-in Web Audio API generator for bronze temple gongs and traditional boat cadence drums.

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

3. **Build for production:**
   ```bash
   npm run build
   ```
